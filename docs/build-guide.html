2

Unplug and strip the AirBeat wiring

  1. Unplug the USB cable first. Never change wiring while the board is powered.
  2. Pull out the buzzer and its two wires. SignBridge doesn't use it.
  3. Pull out every jumper wire. Keep the flex sensor, the resistors and the MPU6050 to reuse.

Starting clean is faster than fixing the old wiring. Two of the old faults were the "3V3" wire sitting on the wrong ESP32 pin and the D33 wire one column off, and both are hard to see.

3

Know how the breadboard connects

  • Each column number has 5 holes in the top half that are joined together, and 5 in the bottom half that are joined to each other but not to the top.
  • The long rails along the edge are joined left to right. Use the top pair: red + for 3V3, blue − for GND.
  • Your breadboard's rails are cut in the middle around column 30. You'll bridge the cut in step 5.
4

Find the pins on your ESP32

Hold the board with the USB port on the left and the chip facing you. The labels are printed next to each pin.

3V3 is the corner pin at the USB end of the bottom row. The corner pin of the top row is VIN, which carries 5 V from USB. Nothing in this build goes to VIN. 5 V on a sensor pin can damage the ESP32.

Only D32 D33 D34 D35 VP work for the sensors. The other analog pins stop reading while Bluetooth is on.

5

Power rails

  1. Female-to-male jumper (red if you have one): ESP32 3V3 → top + rail.
  2. Female-to-male jumper (black): ESP32 GND next to it → top − rail.
  3. Bridge the cut: a short jumper on the + rail from column 29 to 32, and another on the − rail.
6

Five finger circuits

Do this for each finger, one at a time:

  1. Sensor wire 1 → the + rail.
  2. Sensor wire 2 → a hole in the finger's column (top half).
  3. Resistor: one leg in the same column, the other leg in the − rail.
  4. Female-to-male jumper: same column → the finger's ESP32 pin.

Record button (optional)

Put the button across the middle gap. One leg → ESP32 D27, the leg diagonally opposite → − rail. No resistor needed. Skip this if you don't have one; you can record from the phone instead.

10

Plug in USB

  • The ESP32's red power light comes on.
  • The MPU6050's small LED comes on. If it doesn't, the 3V3 wire is on the wrong pin (this was the AirBeat fault).
  • Multimeter on 20 V between + and − rails: about 3.3 V.

Then we upload the SignBridge code. Its serial output shows every finger's reading live, so bend one finger at a time and the right number should move. This PC still needs the Arduino tools and the ESP32's USB driver for that, and I'll set them up with you.

11

Mount everything on the glove

  • Each sensor goes on the back of its finger, printed side facing out, away from the skin. Bent the other way it barely changes.
  • Fix the end with the wires firmly at the knuckle. Let the tip end slide in a small pocket or tape loop, so the sensor isn't stretched.
  • The joint where the wires meet the sensor breaks most often. Cover it with heat-shrink or tape and never bend it.
  • Stick the MPU6050 flat on the back of the hand, chip facing up, with double-sided tape. Keep it the same way round every time.
  • Bundle the wires along the wrist with some slack so moving your hand doesn't pull them out of the breadboard.

If a reading looks wrong

You seeLikely cause
A finger reads 0 all the timeThe sensor wire isn't in that column, or the sensor's wire joint is broken.
A finger reads 4095 all the timeThe resistor doesn't reach GND: wrong column, or the − rail bridge is missing.
A finger's number drifts or jumps randomlyThe jumper to the ESP32 is one column off, so the pin is connected to nothing.
The number barely changes when bendingThe sensor is bent the wrong way, or try the 47k resistor.
The wrong finger's number movesTwo jumpers are swapped at the ESP32.
"MPU not found"MPU LED off: 3V3 problem. LED on: SDA and SCL swapped, or loose.

Practice

Tinkercad version

Tinkercad has no ESP32 and no MPU6050, so this uses an Arduino Uno and only the five finger circuits. The circuit is the same idea, so it's good practice and a clean screenshot for the report. Label it as the Uno practice circuit, not the glove.

T1

Start a circuit

Go to tinkercad.com, sign in, choose Create → Circuit. From the parts list on the right drag in an Arduino Uno R3 and a Breadboard.

T3

Add the code and run it

  1. Click Code, switch the dropdown from Blocks to Text, delete what's there and paste the code below.
  2. Click Start Simulation, then Serial Monitor at the bottom of the code panel.
  3. Click a flex sensor to get its slider and drag it. Its LED gets brighter, and the monitor shows each finger's bend in % and the hand shape (fist, pointing, victory and so on).

Start the simulation with every sensor straight, because the code takes "straight" from the first reading. Bend each one fully once so it learns the range.

// SignBridge - Tinkercad practice circuit (Arduino Uno)
// Tinkercad has no ESP32 and no MPU6050, so this is the 5-finger flex part only, on an Uno.
// It is the same divider circuit as the real glove: 5V -> flex sensor -> pin, 10k from pin -> GND.
//
//   Flex sensors: thumb A0, index A1, middle A2, ring A3, pinky A4
//   LEDs (each through a 220 ohm resistor to GND): thumb 3, index 5, middle 6, ring 9, pinky 10
//
// Start the simulation with every sensor straight. Then drag each sensor's slider:
// its LED gets brighter as the finger bends, and the Serial Monitor shows the bend in %
// and which hand shape the 5 fingers make. The hand-shape table is a simple demo of
// finger patterns, not the trained sign model the real app uses.

const int FLEX_PINS[5] = {A0, A1, A2, A3, A4};   // thumb, index, middle, ring, pinky
const int LED_PINS[5]  = {3, 5, 6, 9, 10};        // PWM pins so brightness can follow the bend
const char* FINGERS[5] = {"thumb", "index", "middle", "ring", "pinky"};

const int BENT_ON = 60;    // a finger counts as bent above 60%
const int BENT_OFF = 40;   // and as straight again below 40%

// Hand shapes: 1 = bent, 0 = straight, in the order thumb index middle ring pinky.
struct Shape { const char* bits; const char* name; };
const Shape SHAPES[] = {
  {"00000", "open hand"},
  {"11111", "fist"},
  {"10111", "pointing (index up)"},
  {"01111", "thumbs up"},
  {"10011", "victory (index + middle up)"},
  {"01110", "call me (thumb + pinky out)"},
  {"11110", "pinky up"},
  {"00011", "three fingers up"},
};
const int NUM_SHAPES = sizeof(SHAPES) / sizeof(SHAPES[0]);

int rest[5];          // reading with the finger straight, taken at start-up
int maxChange[5];     // biggest change seen so far = fully bent
float smooth[5];
bool bent[5];
unsigned long lastPrint = 0;

void setup() {
  Serial.begin(9600);
  for (int i = 0; i < 5; i++) pinMode(LED_PINS[i], OUTPUT);
  delay(200);
  for (int i = 0; i < 5; i++) {
    rest[i] = analogRead(FLEX_PINS[i]);
    smooth[i] = rest[i];
    maxChange[i] = 30;
    bent[i] = false;
  }
  Serial.println("SignBridge Tinkercad ready. All sensors must be straight at start-up.");
  Serial.println("Bend each sensor fully once so it learns its range.");
}

void loop() {
  int pct[5];
  char bits[6];
  for (int i = 0; i < 5; i++) {
    smooth[i] = smooth[i] * 0.7 + analogRead(FLEX_PINS[i]) * 0.3;
    int change = abs((int)smooth[i] - rest[i]);          // works whichever way the reading moves
    if (change > maxChange[i]) maxChange[i] = change;
    pct[i] = constrain(map(change, 0, maxChange[i], 0, 100), 0, 100);
    if (!bent[i] && pct[i] > BENT_ON) bent[i] = true;
    if (bent[i] && pct[i] < BENT_OFF) bent[i] = false;
    analogWrite(LED_PINS[i], map(pct[i], 0, 100, 0, 255));
    bits[i] = bent[i] ? '1' : '0';
  }
  bits[5] = '\0';

  if (millis() - lastPrint > 300) {
    lastPrint = millis();
    for (int i = 0; i < 5; i++) {
      Serial.print(FINGERS[i]); Serial.print(' ');
      Serial.print(pct[i]); Serial.print("%  ");
    }
    Serial.print("| ");
    const char* name = "no match";
    for (int s = 0; s < NUM_SHAPES; s++) {
      if (strcmp(bits, SHAPES[s].bits) == 0) { name = SHAPES[s].name; break; }
    }
    Serial.println(name);
  }
  delay(20);
}
